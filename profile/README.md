## 🏢 What Webanion Is

Webanion is a product and consulting studio founded in February 2021 and led by [Md Moniruzzaman](https://github.com/geniusmonir), its founder and software architect. We work where product, distributed systems and applied AI meet, building AI-native platforms and the multi-tenant infrastructure that runs them, and when the build is done we keep running them: roadmap, releases, servers, store submissions.

The studio is organised around end-to-end ownership rather than a handoff chain. The team that designs the data model is the team that runs the Kubernetes cluster it deploys to, maintains the packages it reuses and takes the app through store review at the end, so no layer of the system is somebody else's problem. Plans and architecture decisions are written down before anything is built, and documentation is part of the definition of done, which keeps the reasoning attached to the code. That is why the portfolio skews toward whole products rather than contributions to someone else's.

* 🔭 **Currently:** taking on platform and AI engagements. MCP servers, autonomous agents and the guardrails around them, durable multi-step workflows, multi-provider model routing, on the belief that the leverage sits in the platform rather than in any one model.
* 🚚 **Running in production:** [Fully Booked](https://fully-booked.uk), a UK minibus and coach booking platform and the operator job-sharing network behind it, around 1,000 users a day, built by Webanion from 2023 and still run by it.
* 🌍 **Where we are:** Bangladesh, UTC+6, working globally remote, with evenings held open for US and EU calls.
* 💬 **Ask us about:** multi-tenant architecture, MCP and agent design, Temporal workflows, Kubernetes you own rather than rent, and taking a product from MVP to scale.

## 🧰 Services

* 🤖 **AI Engineering.** MCP servers that give assistants safe, permissioned access to a product's data and actions, agent pipelines that draft, review and publish behind human approval gates, and integrations with the model providers the use case actually needs. An AI client is treated like any other client of the backend: authenticated, scoped and audited. The proof point is a live MCP server running in production against a real platform.
* 📱 **App Development.** React Native and Expo for iOS and Android, shipped through both stores, and Electron with React for work that lives on the desktop, offline-ready and packaged for Windows, macOS and Linux. The app is never a separate product, it is a surface of the platform, wired to the same backend, auth and data model as every other client.
* 🌐 **Website Development.** Web frontends on React, Next.js and Tailwind against a headless CMS: server-rendered, localized, structured for search engines and AI crawlers alike. The same discipline whether it is a marketing site or the web face of a multi-tenant platform.
* 🛡 **DevOps Engineering.** Kubernetes clusters on owned or cloud hardware, Dockerized services, CI/CD that ships on push, automated TLS, monitoring, scheduled backups and zero-downtime cutovers. The proof point is a production migration off managed cloud with no minute of downtime recorded.
* 🚀 **Startup Development.** A platform taken from architecture to first customers: the data model, the backend, the surfaces, the deploy pipeline and the operating discipline, scoped so the MVP is a thin slice of the real system rather than a throwaway.
* 🎨 **Additional Services.** UI/UX design, headless CMS builds on Strapi, integrations with third-party APIs, architecture reviews and pre-build technical scoping. Smaller pieces, held to the same standard, because they are what keeps a platform coherent.

## 🤝 How We Engage

Four shapes cover nearly every engagement, and which one fits is usually obvious after the first conversation.

| Model | What it looks like |
|---|---|
| **Scoped build** | A defined product or feature set, delivered milestone by milestone. Best when you can describe what done looks like. |
| **Ongoing product ownership** | Webanion runs your product long-term: roadmap, architecture, releases, infrastructure, maintenance. For founders who want an engineering department without building one. |
| **Fractional senior engineering** | Senior architecture and platform capacity inside your existing team: tenancy-model decisions, AI platform design, infrastructure, the hard calls. |
| **Takeover and rescue** | Stabilising, debugging or scaling something that already exists, including migrations and standalone store publishing. Roughly half the historical work. |

How a project actually runs: discovery to pin down the real problem, then a concrete written plan within about a week covering architecture, milestones and an honest read on the timeline. Build in visible increments, with direct communication to the engineers writing the code and scope changes negotiated in the open rather than absorbed silently into drift. Deployment is part of the engagement, not an epilogue. After launch there are two honest endings, a maintenance relationship or a documented handover with recorded walkthroughs so your team runs it alone.

You own everything at the end: code, designs, infrastructure, accounts. NDAs welcome, no lock-in by design. If a timeline is not achievable we say so before the contract, not after.

## 📦 What Is Public Here

Most of this organization is private by contract, which is normal for client platforms and is why the evidence lives on the site rather than in browsable code.

* 📦 **[prebooked](https://github.com/Webanion/prebooked)** is the public one, an embeddable booking widget published on npm that turns any operator website into a booking channel with one embed line. It works from React and Next.js through WordPress, Elementor, Wix, Webflow, Squarespace, Shopify and plain HTML, and it is served by the Fully Booked platform behind it.
* 🌐 **[webanion.com](https://webanion.com)** is itself one of the products. Twenty content types in a Strapi headless CMS on PostgreSQL, a Next.js App Router frontend in five languages, and a companion MCP server that exposes the site's content to AI assistants as typed tools, with an allowlist projection layer deciding field by field what the public surface may return. It runs on the same self-administered k3s cluster as the client platform, with CI/CD that builds and rolls out on every merge.
* 🚚 **[fully-booked.uk](https://fully-booked.uk)** is the longest-running proof: a customer booking site, a React Native operator app on both stores, an admin dashboard and one NestJS GraphQL backend serving every surface, shipping features weekly since 2023 without a rewrite.
